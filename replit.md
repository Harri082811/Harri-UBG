# HarriUBG

HarriUBG is a browser-style entertainment homepage with games, movies, shows, shortcuts, settings, and a direct iframe browser tab.

## Run & Operate

- `pnpm --filter @workspace/harriubg run dev` — run the web app
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm --filter @workspace/harriubg run build` — build the web app

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- UI: React + Vite
- Styling: Tailwind CSS and the existing HarriUBG design tokens
- Build: Vite
